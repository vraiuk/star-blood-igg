# IGG2 — план реализации

Спека: `docs/superpowers/specs/2026-10-18-igg2-two-crowns-rework-design.md` (далее «спека §N»).
Порядок строго последовательный (все фазы трогают `src/sim/game.ts`). После каждой фазы:
`npx tsc --noEmit`, `npm test` зелёный (43 старых + новые), `npm run build`, коммит
Conventional Commits со ссылкой на спеку. TDD для логики sim: сначала тест в `tests/igg2.test.ts`.

## Фаза 1 — Мир как данные (спека §1)
1. `src/data/worlds.ts`: `WorldDef`, `WORLDS.legacy|micro|medium` (контент пока заглушки),
   `features`-флаги. `legacy` = нынешнее поведение.
2. `applyWorld(def)` в `balance.ts`: мутирует `WORLD.width/treeX`, перестраивает `SLOTS` на месте
   (для inWorld: поверхность + 8 колодцев, без кроны). Тест: после applyWorld(micro/medium/legacy)
   позиции слотов и `WORLD` верны; legacy идентичен прежним значениям.
3. `GameOptions.world` (по умолчанию legacy), `game.world`, хранить id в snapshot; `restore`
   применяет мир. Рендерер: `setWorld()` пересоздаёт мировые холсты, фон (тайлинг по ширине),
   свет; `main.ts` вызывает при новом забеге/restore.
4. Ключи хранилища `igg2-*`; титул: «IGG2 · эксперимент», кнопки Росток / Поляна (+`?world=`),
   мета скрыта. Приёмка: оба мира стартуют и рисуются (скриншот).

## Фаза 2 — Камера (спека §2)
`src/data/camera.ts` с числами; `Camera` с режимом follow (окно, SmoothDamp, упреждение от
сглаженной скорости, притяжения, мягкие границы, пиксель-снап, trauma-тряска, зум-подсказки,
Shift-обзор). Legacy — старое поведение. Тесты чистой математики камеры (детерминированно,
dt-шаги). Скриншот: камера на краю мира, на Древе.

## Фаза 3 — Ядро «в мире» (спека §3)
1. Sim: `keeper.purse`, `purseCap`, input API (`setPour/setTake/cycleOption/setSell`), `focus()`,
   залоги `state.pledges`, prepaid-путь оплаты, действия по фокусу (слот, гнездо+развилка,
   колодец, алтарь, дупло W/S, продажа X). `autoLoot=false`: капли только подбираются;
   гусеницы → Казна; доход Древа на рассвете → Казна; удар выбивает 2 капли; гибель →
   высыпать кошелёк, возрождение 8 с без модалки.
2. UI/рендер: плашка фокуса (иконка, имя, роль, капли цены), числа Казны/кошелька в HUD и в
   мире, призрак будущего Круга у алтаря, звон вливания; выключить ring menu / клики / панель
   Древа / quests / revive-модалку / мету в inWorld; клавиши спеки §3.
3. Тесты: частичный залог, постройка, апгрейд и развилка, рост с добором из Казны, W/S у дупла,
   вместимость, выбивание, нет автополёта, гусеницы → Казна, продажа.

## Фаза 4 — Руны и гнёзда (спека §4)
3 руны без мыши (Копьё вдоль взгляда, Молот-прыжок вперёд, Звездопад по скученности впереди),
выключить остальные руны/рулетку/грани/свойства/ранги Хранителя/атрибуты в inWorld;
упрощённая Скрижаль (ранг 0–3 + Форма на 2) открывается только у камня; гнёзда: 5 семейств,
кокон на поверхности, флаги merge/aspects/stars/termite/crown off. Тесты на гейтинг и Форму.

## Фаза 5 — Микро-мир (спека §5, §7 частично)
Контент микро: ночи 1–4 (+повтор), объекты (жеоды, чаща, стадо нейтральных светляков с
респауном), дар Молота, Семя → нести → `won` → переход на Поляну, поражение «С рассвета»
+ одна причина. Проводник-светлячок (шаги микро), карточки тварей при первой встрече.
Тесты: Семя/победа, повтор ночи 4, жеода, нейтралы не мешают концу ночи.

## Фаза 6 — Средний мир (спека §6)
Разломы (спавн, запечатывание, затмение/ответная волна, затихание, запрет раша), Мёртвые
Древа (свет, слоты, HP), Спящие Существа, Стелы, Звёздная Кровь как ключ, открытия по
стадиям с баннером, ночи 1–7 + сдвиг + генератор с перемирием и «зимой», победа.
Тесты на каждое правило.

## Фаза 7 — Слой понятности (спека §7)
Стрелки угроз у края, полоса-карта, цифра дня цветом, экран поражения с причиной, скорость
×2 сразу (×5 только средний), проводник для среднего мира.

## Фаза 8 — Бот, баланс, проверка, деплой (спека §8)
`tests/bot2.ts` (ходит ногами), корридоры баланса; подбор цен/доходов; Playwright-скриншоты
в `production/qa/evidence/igg2-*`; `design/v3-plan.md`-подобная запись в
`design/igg2-notes.md`; пуш `main` и `igg2` → проверить `https://vraiuk.github.io/star-blood-igg/igg2/`.
