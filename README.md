# Звёздная Кровь: Древо Игг

Фанатский 2D tower defense с видом сбоку по мотивам цикла «Звёздная Кровь» Романа Прокофьева
(«Земли Теней»: жизнь теплится только в Кругах вокруг светоносных Игг-Древ).

**▶ Играть: https://vraiuk.github.io/star-blood-igg/**

Посади Семя у границы Теней и вырасти его до Великого Игг-Древа (Семя → Пробуждённый Росток →
Юный Игг → Окрепший Росток → Малое Игг-Древо → Великое Игг-Древо). Камера отдаляется вместе с
Кругом света. Призывай светоносных созданий (светляки, Светожуки, Золотые Стрекозы,
пауки-ткачи), собирай Янтарь, вырывай Звёздную Кровь у Червей и держи Круг сколько сможешь:
10 сюжетных ночей (боссы Имаго-Матерь и Имаго-Палач), дальше — бесконечная ночь за рекордом.

- Гнёзда: уровни 1–3, затем выбор 1 из 2 специализаций. Стрекозы «высвечивают» тварей (+урон от всех).
- Игг-свет жжёт Червей. Броня тварей режет слабые попадания.
- Восходящий: руны Копьё / Молот / Звездопад / Свет по 3 слота Свойств (4-й — Малая Руна Развития),
  Сокровищница Наблюдателя за Звёздную Кровь, рулетка 1 из 3 на рассвете, ранги до «Небо».
- Свет восстанавливается быстрее у ствола Древа.
- Мета-Древо Игг: таланты за Монеты Наблюдателя и Тропы сложности.

```bash
npm install
npm run dev     # http://localhost:5181
npm test        # симуляция и балансные боты
npm run build
```
