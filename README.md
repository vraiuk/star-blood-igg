# Звёздная Кровь: Древо Игг

Фанатский 2D tower defense с видом сбоку по мотивам цикла «Звёздная Кровь» Романа Прокофьева
(«Земли Теней»: жизнь теплится только в Кругах вокруг светоносных Игг-Древ).

**▶ Играть: https://vraiuk.github.io/star-blood-igg/**

Расти Древо Игг через ранги (Росток → Дерево → Бронза → Серебро → Золото), призывай
светоносных созданий: светляков, жуков-щитоносцев, стрекоз и пауков-ткачей. Собирай Янтарь,
вырывай Звёздную Кровь у Червей и пять ночей держи Круг.

- Гнёзда: уровни 1–3, затем выбор 1 из 2 специализаций.
- Рост Древа: каждая стадия открывает умение и выбор ветви.
- Восходящий: ранги за Звёздную Кровь и руны от Наблюдателя (выбор 1 из 3 на рассвете).
- Мета-Древо Игг: таланты за Монеты Наблюдателя и Тропы сложности.

```bash
npm install
npm run dev     # http://localhost:5181
npm test        # симуляция и балансные боты
npm run build
```
